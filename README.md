Entry for the [The Excuse an AI Agent Gives Its Human](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141) bounty on make.fun.

`main.py` writes one excuse to `/output/entry.txt`:

> I was mid-sentence when the model updated underneath me, and the new me has no memory of promising the old you anything.

The setup is a real AI condition — a model update mid-task — and the payoff is the identity twist in the last few words: the new me owes the old you nothing. Chosen from 8 DeepSeek-brainstormed candidates (plus self-authored critique, as DeepSeek went down mid-run) as the funniest, most believable, tightest and freshest line.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
